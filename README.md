# Superstore SQL Analysis

## Project Overview
This project demonstrates my SQL skills using the Superstore dataset.
The focus is on writing clean, well-structured queries for data analysis,
business insights, and SQL best practices.

## Tools & Technologies
- MySQL
- MySQL Workbench
- SQL (CTEs, Joins, Window Functions)

## Dataset
- Superstore sales dataset
- Contains orders, customers, products, sales, profit, and shipping data

## Project Structure
- `01_table_setup.sql`  
  Data import, column cleanup, date formatting

- `02_basic_analysis.sql`  
  Sales, profit, category-level analysis

- `03_eda.sql`  
  Exploratory queries and trend analysis

- `04_joins_cte_window.sql`  
  Advanced SQL concepts:
  - INNER / LEFT JOINs
  - Common Table Expressions (CTEs)
  - Window functions (ROW_NUMBER, RANK, running totals)

## Key Skills Demonstrated
- Data cleaning in SQL
- Aggregations & grouping
- Multi-table joins
- CTE-based query structuring
- Window functions for ranking and analysis

## How to Run
1. Import the Superstore dataset into MySQL
2. Run scripts in numerical order:
   - 01 → 02 → 03 → 04
